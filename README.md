Taller 1: DOM y Nodos con JavaScript

Taller de JavaScript para practicar la manipulación del DOM.

## Temas
- Seleccionar elementos con `querySelector` y `querySelectorAll`
- Crear, insertar, reemplazar y eliminar elementos (`createElement`, `before`, `after`, `replaceWith`, `remove`)
- Modificar estilos y clases con `style` y `classList`
- Recorrer listas con `forEach`
